### 2. إصلاحات الكود العربي (محلل_نحوي.عربي)

#### 2.1 إصلاح اسم الخاصية (الأبناء بدل الأطفال)
**الملف:** `examples/محلل_نحوي.عربي`
**المشكلة:** `العقد_الأطفال` كان خاطئاً والصحيح `العقد_الأبناء`

**الحل:**
```arabic
# قبل
خاص:
    مصفوفة العقد_الأطفال

# بعد
خاص:
    مصفوفة العقد_الأبناء
```

#### 2.2 استبدال حلقات foreach بحلقات while
**الملف:** `examples/محلل_نحوي.عربي`

**المشكلة:** حلقات `لكل...في` تحتاج دعم runtime غير متوفر.

**الحل:** استبدالها بـ `بينما`:
```arabic
# قبل (لا يعمل)
لكل عقدة في هذا.العقد_الأبناء:
    اطبع(عقدة.النوع)

# بعد (يعمل)
مت ي = 0
بينما ي < طول(هذا.العقد_الأبناء):
    اطبع(هذا.العقد_الأبناء[ي].النوع)
    ي = ي + 1
```

#### 2.3 إضافة خاصية عدد_العقد
**الملف:** `examples/محلل_نحوي.عربي`

```arabic
خاص:
    عدد_العقد  # عداد لتتبع عدد العقد
```

#### 2.4 تبسيط طريقة أضف_طفل()
**الملف:** `examples/محلل_نحوي.عربي`

**التغيير:** تجنب استدعاء الدوال على الخصائص مباشرة.

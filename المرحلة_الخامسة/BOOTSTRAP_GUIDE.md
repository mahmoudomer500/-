## 📋 المتطلبات الأساسية

### 1. الملفات المطلوبة
- `arabic_v17.exe` - المترجم الرئيسي
- `self_hosted_output/test_bootstrap.exe` - اختبار Bootstrap
- `self_hosted_output/test_translator.exe` - المترجم الذاتي
- `examples/محلل_لغوي.عربي` - الكود المصدري للمحلل اللغوي
- `examples/محلل_نحوي.عربي` - الكود المصدري للمحلل النحوي
- `examples/مولد_كود.عربي` - الكود المصدري لمولد الكود

### 2. نظام التشغيل
- Windows 10/11 (64-bit)
- Windows Server 2016+

## 🚀 خطوات إكمال دورة Bootstrap

### الخطوة 1: تجميع جميع المكونات

```batch
REM تجميع المترجم الرئيسي (إذا لم يكن موجوداً)
g++ -O2 -Isrc/include -Isrc/core -Isrc/runtime ^
    src/main.cpp src/core/*.cpp src/runtime/*.cpp src/utils/*.cpp ^
    src/core/PEBuilder.cpp -o arabic_v17.exe -lws2_32

REM تجميع اختبار Bootstrap
arabic_v17.exe --mode compiler "examples/bootstrap_ذاتي.عربي" "self_hosted_output/test_bootstrap"

REM تجميع المترجم الذاتي
arabic_v17.exe --mode compiler "examples/مترجم_ذاتي.عربي" "self_hosted_output/test_translator"
```

### الخطوة 2: تشغيل اختبار Bootstrap

```batch
REM الطريقة 1: استخدام ملف الدفعي
run_bootstrap.bat

REM الطريقة 2: التشغيل المباشر
self_hosted_output\test_bootstrap.exe
```

### الخطوة 3: التحقق من عمل المكونات

```batch
REM اختبار المترجم الذاتي
self_hosted_output\test_translator.exe

REM التحقق من الملفات الناتجة
dir self_hosted_output\*.exe
```

## 🔧 استكشاف الأخطاء

### المشكلة 1: خطأ في تجميع مكون
```
❌ خطأ غير متوقع: Cannot determine class
```
**الحل:** تأكد من وجود ملفات الاستيراد المطلوبة

### المشكلة 2: خطأ في تشغيل الملف التنفيذي
```
The code execution cannot proceed because xxx.dll was not found
```
**الحل:** تأكد من وجود ملفات DLL المطلوبة في نفس المجلد

### المشكلة 3: خطأ في ترجمة كود عربي
```
❌ خطأ: فشل في إنشاء كائن من النوع
```
**الحل:** تأكد من صحة بنية الكود المصدر

## 📝 ملاحظات تقنية

### بنية المترجم
```
┌─────────────────┐
│   الكود المصدري  │
│   (بالعربية)    │
└────────┬────────┘
         ↓
┌─────────────────┐
│ المحلل اللغوي    │  ← محلل_لغوي.عربي
│   (Lexer)       │
└────────┬────────┘
         ↓
┌─────────────────┐
│  المحلل النحوي   │  ← محلل_نحوي.عربي
│   (Parser)      │
└────────┬────────┘
         ↓
┌─────────────────┐
│  مولد الكود      │  ← مولد_كود.عربي
│(Code Generator) │
└────────┬────────┘
         ↓
┌─────────────────┐
│  ملف تنفيذي     │
│    (.exe)       │
└─────────────────┘
```

### أنواع الرموز المدعومة
- الكلمات المفتاحية: `متغير، دالة، إذا، بينما، صف`
- العمليات: `+، -، *، /، %`
- المقارنات: `==، !=، >، <، >=، <=`
- العمليات المنطقية: `و، أو، ليس`
